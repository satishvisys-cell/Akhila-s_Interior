# Akhila v2 — Stitch Design System

**Brand:** Akhila  
**Product:** Premium architecture / design / construction platform with Master Tour, Live CCTV, CMS  
**Principles:** Trust · Quality · Precision · Transparency · Premium Craftsmanship

## Visual direction

Cinematic architectural magazine × modern construction technology.

**Do:** editorial asymmetric grids, large Newsreader display type, Manrope UI, 4K architectural photography, generous whitespace, subtle motion cues, muted bronze accents sparingly, max 4px radius.

**Don't:** purple/blue SaaS gradients, heavy glassmorphism, cartoon roundness, equal-card grids as default, cheap multi-layer shadows, cluttered dashboards on public pages.

Header may use **subtle blur/frosted ivory** when scrolled (architectural glass — restrained opacity ~80–95%, 1px stone border). Cards are editorial media frames (image-first), not frosted glass panels.

## Typography

- Display / H1–H2: Newsreader
- Body / Nav / Labels: Manrope
- Labels: uppercase, tracking 0.12–0.3em, sparse

## Motion language (for annotations)

Slow, elegant, purposeful: fade-up 700–900ms, image zoom 1.03 on hover, stagger 70ms, ease `cubic-bezier(0.22, 1, 0.36, 1)`. Respect reduced motion.

## Components

Buttons: bronze fill primary; ghost outline secondary; max 4px radius.  
Project cards: full-bleed 4K image, metadata below or slide-up on hover.  
Live badge: red LIVE pulse.  
Admin: charcoal sidebar, ivory content, dense tables, drawers.

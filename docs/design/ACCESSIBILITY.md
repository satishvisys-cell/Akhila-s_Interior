# Accessibility

- Target WCAG 2.2 AA contrast for text and controls.
- Visible focus rings using bronze/charcoal (never remove outlines without replacement).
- Full keyboard access for nav, tour controls, CCTV controls, galleries, admin builders.
- Semantic landmarks: header, nav, main, aside, footer.
- Media: captions/transcripts for videos; accessible custom players.
- Status badges (LIVE/OFFLINE/MAINTENANCE) not color-only — include text.
- Reduced motion: disable parallax, long zooms, continuous pulses.
- Forms: associated labels, errors announced, required fields indicated in text.
